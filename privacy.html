결은 가입 없이 사용하는 셀프케어 안내 앱입니다. 앱의 마사지 기록과 설정은 기기에 보관되며 개발자 서버로 전송되지 않습니다.

1. 앱이 처리하는 정보

앱은 다음 정보를 현재 기기에만 저장해 기능을 제공합니다.

  • 저장한 루틴의 목록
  • 진행 중인 동작과 반복 횟수, 마사지 기록
  • 선택한 괄사 디자인

앱은 이름, 이메일, 전화번호 등으로 계정을 만들지 않습니다. 카메라, 사진 보관함, 연락처, 위치, 건강 데이터에 접근하지 않으며 광고 식별자, 광고 SDK, 행동 분석 SDK를 사용하지 않습니다. 이 로컬 정보는 개발자에게 수집·공유되지 않습니다.

2. 보관과 삭제

로컬 기록과 설정은 기기에 저장된 동안 유지됩니다. Android에서는 기기 설정의 결 앱 저장공간에서 앱 데이터를 지우거나 앱을 삭제할 수 있습니다. iPhone에서는 결을 앱 삭제하면 앱의 로컬 데이터가 삭제됩니다. 앱 정리하기는 데이터를 남길 수 있습니다. 브라우저 버전에서는 사이트 데이터를 삭제할 수 있습니다.

개발자가 별도의 기록 사본을 보관하지 않으므로 삭제한 내용을 복원해 드릴 수 없습니다. 운영체제의 백업·복원 기능을 이용한 데이터는 사용 중인 기기와 백업 서비스의 설정에 따라 관리됩니다.

3. 문의 이메일

사용자가 직접 지원 이메일을 보내면 회신 주소와 사용자가 보낸 내용이 문의 처리 목적으로 전달됩니다. 필요한 정보만 보내 주시고, 문의와 관계없는 민감한 정보는 포함하지 않아도 됩니다. 문의 내용은 답변 및 문제 해결에 필요한 범위에서 이용하고 더 이상 필요하지 않으면 삭제합니다. 법령상 보관 의무가 있는 경우에는 그 의무를 따릅니다.

이메일 문의는 선택 사항이며, 문의를 보내지 않아도 앱 기능을 사용할 수 있습니다. 문의 정보는 광고나 사용자 추적에 사용하지 않습니다.

4. 외부 링크와 서비스

주요 시연과 지도는 앱에 포함되어 있습니다. 사용자가 참고 자료, 지원 페이지 또는 이메일 링크를 열면 선택한 브라우저나 이메일 앱 등 외부 서비스가 동작합니다. 외부 웹사이트와 이메일 서비스에는 각 서비스의 개인정보 처리방침이 적용됩니다.

이 지원 웹사이트를 제공하는 호스팅 서비스는 페이지 전달과 보안을 위해 IP 주소 등 접속 정보를 자체적으로 처리할 수 있습니다. 결의 지원 페이지에는 별도 분석 도구, 광고 또는 추적 쿠키를 설치하지 않습니다.

5. 아동 정보

결은 아동의 개인정보를 수집하기 위한 서비스를 운영하지 않습니다. 계정이나 개인정보 입력 기능이 없으며, 셀프케어 설명은 성인이 자신의 상태에 맞게 이용하는 것을 전제로 합니다.

6. 방침 변경

앱의 정보 처리 방식이 달라지면 이 페이지의 방침과 시행일을 갱신합니다. 현재 방침은 위에 표시한 앱에 적용됩니다.
